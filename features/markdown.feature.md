# Feature: 通常の Markdown を壊さず数式だけを見分ける

Formula for Pi の利用者として
通常の文章やコードをそのまま読みたい
閉じた表示数式だけを画像で読みたい

## Scenario: 4 種類の数式区切りだけを扱う

- Given 画像経路で数式を描ける Pi がある
- When 4 種類の数式区切りを含む本文を変換する
- Then インライン数式は残り、2 つの表示数式だけが画像になる
