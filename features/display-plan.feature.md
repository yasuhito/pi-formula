# Feature: 描画前に表示数式を含む出力の幅と高さを計画する

表示計画の道具は、コーパスから数式の画像行数と Markdown の折り返しを求め、必要な出力幅と高さを返します。表示経路の違いや描き直し後の寸法も計画に含めます。

組版できない数式はテキストとして計画します。入力を読めない場合や必要な高さが上限を超える場合は、描画前に終了コードと診断を返します。
